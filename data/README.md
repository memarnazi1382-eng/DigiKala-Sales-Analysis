# پوشه‌ی داده

داده‌ی خام و پاک‌شده در این مخزن منتشر نشده است، چون داده برای استفاده‌ی غیرتجاری و با ذکر منبع است.

## منبع

داده‌ی سفارش‌ها از برنامه‌ی داده‌کاوی باز دیجی‌کالا دریافت شده است. فقط فایل سفارش‌ها (`orders.csv`) استفاده شده؛ فایل‌های دیگر برنامه (محصولات، کیفیت، نظرات) استفاده نشده‌اند.

This publication was supported by the Digikala Open Data Mining Program.

## ستون‌های داده‌ی خام (۷ ستون، حدود ۲۰۰ هزار ردیف)

| ستون | معنی |
| --- | --- |
| ID_Order | شناسه‌ی سفارش |
| ID_Customer | شناسه‌ی مشتری |
| ID_Item | شناسه‌ی کالا |
| DateTime_CartFinalize | تاریخ و زمان نهایی‌شدن سبد خرید |
| Amount_Gross_Order | مبلغ |
| city_name_fa | نام شهر (فارسی) |
| Quantity_item | تعداد کالا |

## ساختار محلی

برای اجرای پروژه، فایل‌ها این‌طور قرار می‌گیرند:

- `data/raw/orders.csv`: داده‌ی خام دانلودشده
- `data/processed/orders_clean.csv`: خروجی اسکریپت پاک‌سازی (`src/clean_data.py`)

این دو فایل در `.gitignore` هستند و در مخزن نمی‌آیند.
